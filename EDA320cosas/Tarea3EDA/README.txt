README Tarea 3 EDA320 2024/2do semestre.

El programa compila en aragorn. 

Implemente un menu que usa los mismos datos para cada algoritmo de ordenamiento.
Usando arreglos dinamicos para "copiar" el arreglo original , para que todos los algoritmos ordenen lo mismo 
y el criterio de ordenamiento sea mas preciso.

-Para la compilacion del programa es necesario tener alguna version de gcc.
Aunque en el servidor Aragorn compila sin ningun problema. Tira un mensaje que es probable que salga que es del Makefile,
que el reloj del makefile esta atrasado pero no afecta al codigo.

Para compilar solo se debe tener los archivos : main.c sorting.c Funciones.h y Makefile. con colocar
make en la terminal, compilara y se puede make run para normal o make valgrind para ver la memoria.
