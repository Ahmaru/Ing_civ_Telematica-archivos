Esta base de datos esta creada en PostgreSQL, por lo que se requiere la ultima version instalada en su dispositivo.

Instrucciones de ejecución: Descargue el zip con el contenido, en el deberia tener un archivo llamado "DB_Consulta_SQL.sql", desde el terminal
ejecutar la instruccion "psql -U postgres -d tu_base_de_datos -f DB_Consulta_SQL.sql" y con esto ya tienes todo el contenido la base de datos.

Si no se rellenan los datos de las tablas de solicitudes de funcionalidad y error copie la instruccion del txt con el respectivo nombre y
ejecutela como query.

En el txt llamado "comandos.txt" encontrara la lista con todos los comandos para hacer las consultas.
