# matreforce2
Una version mejorada y optimizada de MatReforce en lenguaje C++ y Qt6,creado pensando en los contenidos de la Prueba de Admisión para la Educación Superior (PAES).

## Características
Generadores de ejercicios de:
- Porcentajes
- Potencias
- Raices de polinomios
- Ecuaciones cuadraticas
- Divisiones

## Instalación

### Dependencias

- g++
- Make
- qmake6

### Instrucciones
- Descargar y descomprimir el codigo de fuente.
- Con un terminal, ingresar al directorio del proyecto `src` y ejecutar qmake.
- Ejecutar el Makefile creado por qmake.
- Ejecutar el programa.

### Ejemplo en terminal usando git
```
git clone git@github.com:sebadaba/matreforce2.git
cd matreforce2/src/
make
./matreforce
!Idealmente compilar y ejecutar en QtCreator 5.15 hacia arriba.!
```
