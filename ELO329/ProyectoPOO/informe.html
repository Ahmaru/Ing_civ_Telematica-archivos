Informe proyecto ELO329 MATREFORCE 2

1. Descripción del problema

El problema a solucionar inicialmente era sobre el material educativo sobre la prueba PAES. Pero ese problema se fue ramificando a la capacidad de encontrar material y soluciones de problemas en temas específicos para la PAES. Nuestra forma de acercamiento al problema fue recopilar información sobre los materiales que se tienen a disposicion y preguntas de pruebas anteriores, esto siendo un enfoque completo a PAES M1 y M2.

2. Análisis del problema

El sistema que resuelve el problema se basa en interacciones entre usuario y la interfaz grafica.

El sistema interactúa con [interacciones de usuario, codigo base, referencias para los creadores del codigo.].

Nuestro sistema esta fuertemente conectado con los temas mencionados en los formularios y temarios PAES, esto quiere decir que cada vez que cambien los temas a evaluar se debera actualizar el codigo base de generador de problemas.

3.Casos de Uso

  • Caso de uso #1

    Usuario selecciona modo.
    • Este caso es vital para el funcionamiento ya que la primera interaccion del usuario con el programa sera la seleccion de modo.

  • Caso de uso #2

    Usuario genera un ejercicio.
    • El modo generador es donde se puede seleccionar entre varios tipos de ejercicios, este modo no estara temporizado y te brinda la respuesta luego de una interaccion con el boton destinado a ello.

  • Caso de uso #3

    Usuario ocupa modo desafio. Modo que se basa en ser un desafio de 60 segundos donde aparecera cualquier tipo de pregunta y que el estudiante debe responder correctamente para ir ganando un puntaje y sumar tiempo.

Se tomo el ejemplo del caso de uso 2 para montar el diagrama de secuencia.
